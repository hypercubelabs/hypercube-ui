States

Every screen shows up four ways: with content, empty, loading and with an error. Design all four.

Empty

.empty-state .glyph .es-h p .sm

Say what will show here and offer the first step, if there is one.

No projects yet

Create the first project to organise the team's tasks.

Loading indicator

.hc-loader .hc-loader.lg .is-busy

The one and only house loader, the same as Datacube's: a hexagon with a stroke running round the outline. Colour comes from the text. 14 px in lists and buttons, 24 px for a page. Always this one, never another.

Loading tasks…
Code
<span class="hc-loader" role="status" aria-label="Loading"></span>
<span class="row" style="color:var(--text-2)"><span class="hc-loader" aria-hidden="true"></span>Loading tasks…</span>
<span class="hc-loader lg" role="status" aria-label="Loading"></span>
<button class="btn btn-secondary" disabled><span class="hc-loader" aria-hidden="true"></span>Generating</button>
<button class="btn btn-primary is-loading">Saving</button>

Alerts

.alert .info .ok .warn .danger

Inside the page, near what it affects. For something passing, use a toast (see Overlays).

Heads up. Deliveries out of order show dashed.

Could not save. The server did not answer in time.
