Pieces/Buttons

Buttons

One primary button per area. A verb on the label: "Save", not "OK".

Kinds

.btn .btn-primary .btn-secondary .btn-ghost .btn-danger

Primary is a black pill (lime in dark). Danger only for what deletes.

Code
<button class="btn btn-primary">Save</button>
<button class="btn btn-secondary">Share</button>
<button class="btn btn-ghost">Filter</button>
<button class="btn btn-danger">Delete</button>
<button class="btn btn-danger-ghost">Remove</button>

With an icon

.btn > svg.i

The icon comes before the text, 14 px.

Code
<button class="btn btn-primary"><svg class="i" width="14" height="14"><!-- Lucide plus, stroke 1.8 --></svg>New task</button>
<button class="btn btn-secondary"><svg class="i" width="14" height="14"><!-- Lucide share-2, stroke 1.8 --></svg>Share</button>
<button class="btn btn-ghost"><svg class="i" width="14" height="14"><!-- Lucide list-filter, stroke 1.8 --></svg>Filter</button>

Sizes

.btn-xs .btn-sm .btn .btn-lg .btn-block

22, 26, 30 and 36 px. On phones the touch area grows on its own inside bars.

Code
<button class="btn btn-secondary btn-xs">Tiny</button>
<button class="btn btn-secondary btn-sm">Small</button>
<button class="btn btn-secondary">Medium</button>
<button class="btn btn-secondary btn-lg">Large</button>
<div style="width:100%;max-width:320px"><button class="btn btn-primary btn-block btn-lg">Sign in</button></div>

States

:disabled .is-loading aria-disabled

Loading keeps the width; disabled explains why in a tooltip.

Code
<button class="btn btn-primary is-loading">Saving</button>
<button class="btn btn-secondary is-loading">Loading</button>
<button class="btn btn-primary" disabled>Save</button>
<span data-tip="Only the project owner can delete"><button class="btn btn-danger" aria-disabled="true">Delete</button></span>

Icon button

.ibtn .ibtn-sm .ibtn-xs .on

Always with aria-label and a tooltip (data-tip).

Code
<button class="ibtn" aria-label="Add" data-tip="Add"><svg class="i" width="16" height="16"><!-- Lucide plus, stroke 1.8 --></svg></button>
<button class="ibtn on" aria-label="Filter on" data-tip="Filter on"><svg class="i" width="16" height="16"><!-- Lucide list-filter, stroke 1.8 --></svg></button>
<button class="ibtn" aria-label="More actions" data-tip="More actions"><svg class="i" width="16" height="16"><!-- Lucide ellipsis, stroke 1.8 --></svg></button>
<button class="ibtn ibtn-sm" aria-label="Copy" data-tip="Copy"><svg class="i" width="14" height="14"><!-- Lucide copy, stroke 1.8 --></svg></button>
<button class="ibtn ibtn-xs" aria-label="Close" data-tip="Close"><svg class="i" width="13" height="13"><!-- Lucide x, stroke 1.8 --></svg></button>
<button class="ibtn" disabled aria-label="Delete"><svg class="i" width="16" height="16"><!-- Lucide trash-2, stroke 1.8 --></svg></button>

Action group

.row .sp

Actions on the right; the primary one last. On phones the bar wraps and takes the full width.

Code
<div class="row" style="width:100%;flex-wrap:wrap;gap:8px">
  <button class="btn btn-ghost"><svg class="i" width="14" height="14"><!-- Lucide archive, stroke 1.8 --></svg>Archive</button>
  <span class="sp"></span>
  <button class="btn btn-secondary">Cancel</button>
  <button class="btn btn-primary">Save</button>
</div>
