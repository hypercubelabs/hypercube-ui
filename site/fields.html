Pieces/Fields

Fields

The label is always visible above the field. An error says what to do, not only what went wrong.

Text

.field .label .input .hint

.field stacks label, field and hint with 6 px between them.

Shows in the sidebar and in notifications.
Code
<div class="field" style="width:100%;max-width:360px">
  <label class="label" for="c-name">Project name</label>
  <input class="input" id="c-name" placeholder="e.g. New website">
  <span class="hint">Shows in the sidebar and in notifications.</span>
</div>

With an error

.input.is-error .err aria-invalid

Tie the error to the field with aria-describedby.

Write the full email, like ana@company.com
Code
<div class="field" style="width:100%;max-width:360px">
  <label class="label" for="c-mail">Email</label>
  <input class="input is-error" id="c-mail" value="ana@company" aria-invalid="true" aria-describedby="c-mail-e">
  <span class="err" id="c-mail-e"><svg class="i" width="12" height="12"><!-- Lucide circle-alert, stroke 1.8 --></svg>Write the full email, like ana@company.com</span>
</div>

Search

.inwrap > svg.i + .input + .kbd

Show a shortcut on the right only if it really exists.

/
Code
<div class="inwrap" style="width:100%;max-width:360px"><svg class="i" width="13" height="13"><!-- Lucide search, stroke 1.8 --></svg><input class="input" placeholder="Search" aria-label="Search"><span class="kbd">/</span></div>

Select, long text, date

.select .textarea input[type=date]

Use the browser select: on phones it opens the system picker.

Code
<div class="ex-grid">
  <div class="field"><label class="label" for="c-st">Status</label><select class="select" id="c-st"><option>In progress</option><option>Review</option><option>Done</option></select></div>
  <div class="field"><label class="label" for="c-date">Due</label><input class="input" type="date" id="c-date" value="2026-11-20"></div>
  <div class="field" style="grid-column:1/-1"><label class="label" for="c-desc">Description</label><textarea class="textarea" id="c-desc" rows="3">What needs to be ready, and for whom.</textarea></div>
</div>

Check, choose, switch

.check .check.round .radio .toggle

Always with a clickable label next to it.

Code
<div class="col" style="gap:10px">
  <label class="row"><input type="checkbox" class="check" checked> Email me</label>
  <label class="row"><input type="checkbox" class="check"> Notify my phone</label>
  <label class="row"><input type="radio" class="radio" name="c-r" checked> Only me</label>
  <label class="row"><input type="radio" class="radio" name="c-r"> The whole team</label>
  <label class="row"><input type="checkbox" class="toggle" checked> Automatic dark theme</label>
</div>

Disabled

:disabled

Say why it is disabled, next to the field.

Only account admins can change the address.
Code
<div class="field" style="width:100%;max-width:360px">
  <label class="label" for="c-dom">Address</label>
  <input class="input" id="c-dom" value="acme.example.com" disabled>
  <span class="hint">Only account admins can change the address.</span>
</div>

.field in a grid, .row of actions
