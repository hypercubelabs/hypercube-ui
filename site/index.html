How to use

Copy the src and fonts folders into your project and import one file:

<link rel="stylesheet" href="hc/index.css">
<script type="module" src="hc/elements.js"></script>  <!-- only if you want the behaviour -->

Then write the markup of each piece as shown in the catalog. In React use className on normal tags and class on hc-* tags; in Blazor and Astro the markup is the same.

Rules for every screen

  • One animation per area. Colour only for state: working, needs you, error.
  • Nothing changes size between states, and no piece of information shows twice.
  • Real state only: no made-up progress text.
  • A button only shows if its action exists. What does not work yet stays off the screen.
  • Every screen is built for phones too: 40 px touch targets, the sidebar in a drawer, a bottom sheet instead of floating menus.
